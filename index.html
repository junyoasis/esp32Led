01. 보드 준비

Thonny에서 BLE 샘플 코드를 실행하고, ESP32 전원을 유지하세요.

02. 내 장치 선택

장치 찾기를 누르고 본인의 이름이 표시된 ESP32를 선택해 연결하세요.

03. LED 켜고 끄기

ON / OFF를 누르면 명령을 전송합니다. 보드의 응답은 통신 기록에서 확인하세요.

연결이 안 되나요? · 호환 환경과 샘플 코드 안내

Windows·macOS의 Chrome/Edge 또는 Android Chrome에서 HTTPS 주소를 직접 여세요. iPhone/iPad의 일반 Safari·Chrome과 Firefox는 이 실습의 Web Bluetooth를 지원하지 않습니다. 앱 내 미리보기 대신 별도 브라우저 탭을 이용하세요.

장치가 보이지 않으면 전원, 코드 실행 여부, 이름을 확인하세요. 다른 앱이 연결 중이면 연결을 해제하세요. 이 샘플은 서비스 UUID를 광고하지 않아 이름 기준으로 검색합니다. OS 설정에서 미리 페어링할 필요 없이 이 페이지에서 선택합니다.

샘플 호환: Nordic UART Service · RX에 ON / OFF 전송, TX 알림 수신. GPIO 2에 내장 LED가 없는 보드는 핀을 수정해야 합니다. 전원 LED는 제어되지 않을 수 있습니다.

주의: 샘플의 한글 응답은 기본 BLE 알림 크기를 초과할 수 있습니다. 응답이 깨지면 보드의 응답을 self.send("ON") / self.send("OFF")로 바꾸세요. 웹앱은 두 형식을 모두 인식합니다. 한글 장치 이름은 UTF-8 바이트 수 기준으로 광고 전체 31바이트 이내여야 하므로 긴 이름은 줄이세요.
